# R34Hub — Multi-Board Booru & Rule 34 HD Video/Art Explorer

**Live Web App:** **[https://r34hub-five.vercel.app](https://r34hub-five.vercel.app)**

R34Hub is a fast, dark-mode web aggregator and media explorer for 11 connected anime, Rule 34, furry, and sakuga booru imageboards. Built for instant tag search, inline HTML5 video streaming, 1-click AI filtering, and local-first privacy.

## Key Features

1. **11 Connected Booru Boards + Parallel Multi-Board Mode:** Switch between `Rule34.xxx`, `Danbooru`, `e621`, `Yande.re`, `Paheal`, `Konachan`, `Safebooru`, `Sakugabooru`, `XBooru`, `TBIB`, and `AIBooru` in 1 click.
2. **Custom Inline HTML5 Video Player in Grid, Posts & Lightbox:** Play/pause, scrub timeline progress, view live duration badges, toggle mute, and enter fullscreen directly inside the masonry grid or full-screen Lightbox.
3. **Instant `0ms` Tag Autocomplete & Tag Exclusion (`-tag`):** Category-colored tag suggestions (`character`, `copyright`, `artist`, `meta`, `general`) with post counts, plus 1-click `+` include, `−` exclude (`-ai_generated`), and permanent tag blocklist.
4. **Local-First Collections, Pinned Searches & Full JSON Backup:** Organize saved posts into custom folders (`Favorites`, `Characters`, `Videos`, or custom collections) and export/import your entire library as a portable `.json` file.
5. **High-Speed Media Proxy (`/api/media`) & RSS Feed (`/feed.xml`):** Bypasses hotlink restrictions across all boards and exposes a live RSS 2.0 feed at [`/feed.xml`](https://r34hub-five.vercel.app/feed.xml) and sitemap at [`/sitemap.xml`](https://r34hub-five.vercel.app/sitemap.xml).
